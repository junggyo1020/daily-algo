# daily-algo

하루 한 문제, Java, 퇴근 후 45분. 실력을 유지하고, 점수가 내려간 유형을 매주 정확히 아는 것이 목표다.

## 매일 (45분)

```bash
cd ~/willy/GitHub/daily-algo && claude
```
그리고 `오늘 문제` 라고 입력하면 `algo-daily` 스킬이 전 과정을 진행한다.

| 시간 | 단계 |
|---|---|
| 30초 | `algo.py today` 가 복습과 신규 중 하나를 고른다 |
| 8분 | 개념 설명. 신규일 때만 하고 문제 힌트는 넣지 않는다 |
| 25분 | 풀이. **목표시간을 넘기면 중단한다.** 못 푼 문제는 다음 날 1순위 복습으로 올라온다 |
| 7분 | 피드백. 복잡도, Java API, 반례 |
| 5분 | 기록, 커밋, push |

피곤한 날은 **축소모드 25분**으로 돌린다. 복습 한 문제와 기록만 남긴다.

## 주 1회 (토요일 20분)

`주간 진단` 이라고 입력하면 `algo-weekly` 스킬이 약점 진단, 다음 주 7일 계획, 대시보드 갱신을 차례로 돌린다.

## 설계의 핵심 3가지

### 1. 간격 반복

결과에 따라 같은 문제를 다시 푼다.

| 결과 | 다음 복습 |
|---|---|
| 미해결 | 1일 뒤 |
| 힌트 후 정답 | 3일 뒤 |
| 시간초과 정답 | 7일 뒤 |
| 시간내 정답 1회 | 21일 뒤 |
| 시간내 정답 2회 연속 | 60일 뒤 |
| 시간내 정답 3회 연속 | 목록에서 제거 |

새로 푼 문제만 쌓으면 한 달 뒤 같은 유형에서 다시 막힌다. 복습을 주 5일 중 2일로 고정한 이유다.

### 2. 점수 감쇠

```
현재 점수 = 감쇠 전 점수 × 0.5^(마지막으로 푼 뒤 지난 날 / 60)
```

점수는 60일마다 절반으로 줄어든다. 마지막으로 푼 날에서 30일이 지나면 71%가 된다. 최근에도 풀리는지를 점수에 반영하려는 계산이다.

낮은 점수는 두 가지로 갈린다.

| 모양 | 뜻 | 처방 |
|---|---|---|
| 감쇠 전 점수가 높고 마지막으로 푼 날이 오래됨 | 안 푼 기간만큼 내려갔다 | 복습 한 문제 |
| 감쇠 전 점수 자체가 낮음 | 학습 공백 | 개념부터 |

대시보드가 이 둘을 구분해 보여준다.

### 3. 틀린 이유 분류

모든 기록에 8종 원인을 붙인다.

| 원인 | 뜻 |
|---|---|
| 유형미인지 | 어떤 알고리즘을 써야 할지 떠올리지 못함 |
| 복잡도오판 | 시간이나 공간 복잡도를 잘못 계산해 시간초과 |
| 경계조건 | 빈 입력, 원소 1개, 최댓값, 동일값 같은 끝값 |
| 자료구조선택 | 답은 맞지만 비효율적이거나 부적절한 자료구조 |
| 구현실수 | 인덱스, off-by-one, 조건문 뒤집힘 같은 코딩 실수 |
| 문제오독 | 요구사항을 잘못 읽음 |
| API미숙 | Java 표준 API 사용법이 막힘 |
| 수학오버플로 | int 오버플로, 모듈러, 조합과 확률 공식 |

유형과 원인을 교차하면 "동적 계획법 점수가 낮다"가 "동적 계획법은 점화식 수립에서 막힌다"로 바뀐다. **시간 안에 맞혔어도 과정에서 틀린 부분이 있으면 분류한다.**

## 12주 사이클

단계는 기록 상태로 바뀐다. 교대 근무나 야근으로 날짜가 밀려도 날짜만으로 단계가 넘어가지 않는다.

| 단계 | 조건 | 하는 일 |
|---|---|---|
| 진단 | 아직 안 푼 유형이 남음 | 12유형을 Lv.1~2로 한 번씩 푼다. 현재 상태를 측정하는 기간이다 |
| 보강 | 모든 유형을 한 번씩 풀었고 점수 60 미만인 유형이 있음 | 약점 유형 집중, 유형 공개, 한 주에 새 개념 2개까지 |
| 실전 | 모든 유형이 60 이상 | Lv.2~3 **블라인드**(유형 비공개), 주말 타임어택 |

실전과 보강을 오가는 상태가 정상이다. 단계는 내려갈 수도 있다.

## 명령어

```bash
python3 scripts/algo.py today     # 오늘 뭘 풀어야 하는지
python3 scripts/algo.py stats      # 터미널 요약 (점수 표, 틀린 이유 분포)
python3 scripts/algo.py export     # dashboard/data.json 생성
python3 scripts/algo.py log --help # 기록 옵션
python3 scripts/verify.py          # 하네스 자체 검사
```

`verify.py`는 스킬과 에이전트와 엔진을 고친 뒤에 돌린다. 이 저장소에서 가장 위험한 고장은 **문서와 코드의 불일치**다. 문서는 "60일 뒤 복습한다"고 하는데 코드가 거기 도달하지 못하면, 일어나지 않는 일을 믿고 공부하게 된다. 그런 종류와 표현 규칙(`CLAUDE.md`) 위반을 함께 검사한다.

## 구조

```
data/log.jsonl        모든 지표의 출처. 점수와 복습 일정이 여기서 파생된다

scripts/algo.py       학습 엔진 (추천, 점수, 복습 목록, 연속 기록, export)
scripts/verify.py     문서와 코드의 불일치 검사
src/main/java/daily/  날짜별 풀이. java 파일 단독 실행 (java <경로>)
notes/YYYY-MM-DD.md   당일 개념, 막힌 지점, 배운 API
dashboard/            data.json 과 발행된 대시보드 주소
_workspace/           주간 사이클 중간 산출물. 지우지 않는다
.claude/agents/       진단, 커리큘럼, 스카우트, 대시보드 에이전트 4개
.claude/skills/       algo-daily, algo-concept, algo-feedback, algo-weekly, algo-dashboard
```

## 플랫폼

프로그래머스가 1순위다. 백준은 2026-04-28부터 중단되어 있다. 데이원컴퍼니가 인수했고 재오픈이 연기된 상태다(2026-11-09 확인). 재개되면 문제 수와 난이도 분포가 넓으므로 스카우트 에이전트가 매번 상태를 확인해 1순위를 바꾼다.
