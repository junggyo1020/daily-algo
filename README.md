# daily-algo

하루 한 문제, Java, 퇴근 후 45분. 목표는 **많이 푸는 것이 아니라 실력이 녹슬지 않게 유지하고
녹슨 지점을 매주 정확히 아는 것**이다.

## 매일 (45분)

```bash
cd ~/willy/GitHub/daily-algo && claude
```
그리고 `오늘 문제` 라고 입력하면 `algo-daily` 스킬이 전 과정을 진행한다.

| 시간 | 단계 |
|---|---|
| 30초 | `algo.py today` — 복습인지 신규인지 엔진이 결정 |
| 8분 | 개념 리마인드 (신규일 때만, 문제 힌트 없음) |
| 25분 | 풀이. **목표시간 초과 시 중단** — 못 푼 문제는 내일 1순위 복습으로 올라간다 |
| 7분 | 피드백 (복잡도 · Java API · 반례) |
| 5분 | 기록 + 커밋 |

피곤한 날은 **축소모드 25분**(복습 1문제 + 기록)으로 돌린다. 기록만 빠뜨리지 않으면 지표가 유지된다.

## 주 1회 (토요일 20분)

`주간 진단` → `algo-weekly` 스킬이 약점 진단 → 다음 주 7일 계획 → 대시보드 갱신을 돌린다.

## 설계의 핵심 3가지

**1. 간격 반복.** 결과에 따라 같은 문제를 1·3·7·21·60일 뒤에 다시 만난다
(실패 1일 / 힌트 3일 / 시간초과 7일 / 정답 21일 / 2회 연속 정답 졸업).
새 문제만 푸는 공부는 쌓이지 않는다. 이게 일반적인 "하루 한 문제"와의 유일한 차이다.

**2. 숙련도 감쇠.** `mastery = base × 0.5^(경과일/60)`.
한 번 잘 풀었다는 사실이 아니라 **최근에도 되는가**를 점수로 본다. 30일 방치하면 71%로 떨어진다.
그래서 낮은 점수는 두 가지로 갈린다 — `base` 높고 오래됨 = **녹슴**(복습 1문제로 회복),
`base` 낮음 = **공백**(개념부터). 대시보드가 이 둘을 구분해 보여준다.

**3. 오답 원인 분류.** 모든 기록에 8종 원인을 태깅한다
(`유형미인지` `복잡도오판` `경계조건` `자료구조선택` `구현실수` `문제오독` `API미숙` `수학오버플로`).
유형 × 원인 교차표가 "DP가 약하다"를 "DP는 점화식 수립에서 막힌다"로 바꿔준다.
**최종 정답이어도 과정에서 틀린 건 태깅한다.**

## 12주 사이클

단계는 날짜가 아니라 상태로 전환된다 — 교대·야근으로 날짜가 밀려도 단계가 멋대로 넘어가지 않는다.

| 단계 | 조건 | 하는 일 |
|---|---|---|
| 진단 | 표본 0인 유형이 남음 | 12유형을 Lv.1~2로 한 번씩. 목적은 점수가 아니라 **측정** |
| 보강 | 전 유형 터치, 숙련도 60 미만 존재 | 약점 집중, 유형 공개, 주 2개 새 개념 상한 |
| 실전 | 전 유형 60 이상 | Lv.2~3 **블라인드**(유형 비공개) + 주말 타임어택 |

실전 ↔ 보강을 왕복하는 상태가 "유지 국면"이다. 단계 역행은 정상이다.

## 명령어

```bash
python3 scripts/algo.py today     # 오늘 뭘 풀어야 하는지
python3 scripts/algo.py stats      # 터미널 요약 (숙련도 표 + 오답원인 분포)
python3 scripts/algo.py export     # dashboard/data.json 생성
python3 scripts/algo.py log --help # 기록 옵션
```

## 구조

```
data/log.jsonl        단일 진실 원천 — 모든 지표가 여기서 파생된다
data/types.json       12유형 + 유형별 목표시간 + 오답원인 8종
scripts/algo.py       학습 엔진 (추천·숙련도·복습큐·스트릭·export)
src/main/java/daily/  날짜별 풀이 (java 파일 단독 실행: java <경로>)
notes/YYYY-MM-DD.md   당일 개념·막힌 지점·배운 API
dashboard/            data.json + 발행된 대시보드 URL
_workspace/           주간 사이클 중간 산출물 (지우지 않는다)
.claude/agents/       진단·커리큘럼·스카우트·대시보드 에이전트 4개
.claude/skills/       algo-daily / algo-concept / algo-feedback / algo-weekly / algo-dashboard
```
